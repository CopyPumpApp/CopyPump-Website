# CopyPump wordmark font

Manrope ExtraBold (800), normal, self-hosted WOFF2 containing only the seven unique characters in `CopyPump`. It is intentionally scoped to `.brand-wordmark`; body typography is unchanged.

- Source: [Google Fonts CSS API](https://fonts.googleapis.com/css2?family=Manrope:wght@800&display=swap&text=CopyPump), downloaded 2026-09-20 with a modern Chromium user agent (v20).
- Upstream: [The Manrope Project](https://github.com/googlefonts/manrope).
- License: SIL Open Font License 1.1, included in `OFL.txt` from [Google Fonts](https://github.com/google/fonts/blob/main/ofl/manrope/OFL.txt).

There is no runtime Google Fonts request. Keep the preload in `index.html` and the CSS source URL synchronized when replacing this file.
